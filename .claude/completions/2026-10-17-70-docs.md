**Decisions**

- Quickstart shell fences are `bash test` (run by `docs:check`) or `bash notrun` with a `> Not run: <reason>` quote under the same heading. A plain `bash` fence in a
  quickstart fails the check, so no command is left unchecked silently. The GCP and AWS pages are therefore entirely `notrun`, each with its reason.
- The migration guide links the generated `docs/unsupported.md` instead of inlining the 55 not-supported rows. The acceptance says the guide "lists every unsupported
  feature"; the link satisfies it only because the list is generated and checked current. Say so if you want them inlined.
- `docs/migration.md` is the file name `compat.md` already linked to.
- The runner needs ports 8080 and 8081 free and says so when they are not. It makes its own database on the test server and passes it as `QCLOUD_DATABASE_URL`.
